\# LMS — платформа онлайн-обучения



Веб-приложение, где каждый желающий может размещать свои полезные материалы

и курсы. Пользователи записываются на курсы, проходят уроки, а авторы

получают обновления о своих учениках. Оплата курсов — через Stripe,

уведомления и фоновые задачи — через Celery.



\## Технологии



\- Python 3.11, Django, Django REST Framework

\- PostgreSQL 16

\- Redis (брокер и бэкенд результатов для Celery)

\- Celery (периодические задачи — рассылки об обновлениях материалов)

\- Stripe (приём платежей за курсы, тестовый режим)

\- Docker, Docker Compose
